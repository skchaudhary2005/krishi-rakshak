# Krishi Rakshak Complete Web Frontend

React + Vite frontend for the existing Krishi Rakshak services. Includes Spline hero, crop scanner, prediction/advice, history, 7-day weather, expert agriculture information, consultant referrals, Krishi AI chat and settings.

The frontend calls the existing backend through `VITE_API_BASE_URL` and the Spline scene through `VITE_SPLINE_PUBLIC_URL`.
