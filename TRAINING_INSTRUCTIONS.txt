CROP DISEASE DETECTOR - TRAINING INSTRUCTIONS
===============================================================================

📁 DATASET STATUS:
- Total Images: 28,336 (2 corrupted files removed)
- Classes: 58 disease types
- Sources: PlantVillage (26,172) + Indian Crops (2,164)
- Location: datasets/combined_all/train

===============================================================================
HOW TO TRAIN
===============================================================================

OPTION 1: Double-click TRAIN.bat
   - Opens automatically
   - Shows progress in window
   - Takes 15-20 minutes

OPTION 2: Run in PowerShell
   python train_final.py

===============================================================================
TRAINING DETAILS
===============================================================================

⚡ ULTRA SPEED CONFIGURATION:
- Image Size: 96x96 (small = fast)
- Batch Size: 160 (large = faster)
- Epochs: Maximum 5 (quick training)
- Target: 80% accuracy
- Model: MobileNetV2 (2.6M parameters)

🎯 FEATURES:
✅ Automatic image validation (skips corrupted files)
✅ Early stopping (stops if accuracy reached)
✅ Best model auto-save
✅ Training progress display
✅ Minimal augmentation for speed

===============================================================================
OUTPUT FILES
===============================================================================

All files saved to: models/final_model/

1. best_model.h5 - Trained model (use this!)
2. classes.json - 58 disease class names
3. config.json - Training configuration
4. training_log.json - Accuracy/loss history

===============================================================================
AFTER TRAINING - DEPLOY TO WEB
===============================================================================

1. Convert model to TensorFlow.js:
   python convert_to_tfjs.py

2. Update React app:
   - Model will be in: public/models/final_model/
   - Update src/services/realModelService.ts to point to new model

3. Test web app:
   npm run dev

===============================================================================
TROUBLESHOOTING
===============================================================================

❌ If training crashes with "broken data stream":
   - Already fixed! Script validates all images first

❌ If "cannot import tensorflow" in new terminal:
   - Use the SAME PowerShell window you have open now
   - Don't open new terminals

❌ If memory errors:
   - Reduce BATCH_SIZE to 128 in train_final.py

❌ If accuracy too low:
   - Increase EPOCHS to 10 in train_final.py
   - Increase IMG_SIZE to 128 in train_final.py
