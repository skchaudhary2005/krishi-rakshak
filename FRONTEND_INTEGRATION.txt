HOW TO RUN
================================================================================

STEP 1: Start the Python API Server
------------------------------------
Option A: Double-click START_API.bat
Option B: Run in terminal: python api_server.py

The server will start on: http://localhost:5000

STEP 2: Start the React Frontend
---------------------------------
In a NEW terminal:
   npm run dev

The frontend will start on: http://localhost:5173

STEP 3: Test Disease Detection
-------------------------------
1. Open http://localhost:5173 in your browser
2. Click "Start Detection" or "Upload Image"
3. Select a crop disease image
4. Click "Analyze"
5. View results with:
   - Disease name
   - Crop type
   - Confidence score
   - Top 5 predictions
   - Treatment recommendations (from Gemini AI)

      ↓
Beautiful Results Display

================================================================================
API ENDPOINTS
================================================================================

1. GET /api/health
   - Check if API is running
   - Returns: {status: 'healthy', classes: 23}

2. POST /api/predict
   - Upload image for disease detection
   - Form data: 'image' file
   - Returns: Full prediction with top 5 results

3. GET /api/classes
   - Get all 23 disease classes
   - Returns: List of all detectable diseases

================================================================================
TROUBLESHOOTING
================================================================================

❌ API Not Starting:
   - Make sure you're in the correct PowerShell window
   - TensorFlow bug prevents new terminals from working
   - Use the current PowerShell session

❌ Frontend Can't Connect:
   - Verify API is running on http://localhost:5000
   - Check browser console for errors
   - Make sure CORS is enabled (already configured)

❌ Low Accuracy:
   - Model achieves 72% on test data
   - Shows top 5 predictions (97% top-3 accuracy)
   - Use Gemini AI for additional insights
